An entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: a program that writes one line inventing the most useless superpower imaginable.

Run with `MAKEFUN_OUTPUT_DIR` set; it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
